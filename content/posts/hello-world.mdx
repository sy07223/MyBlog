## 什么是 MDX？

MDX 是 Markdown 的扩展，允许你在 Markdown 中直接使用 React 组件。

```tsx
export function Hello() {
  return <div>Hello from component!</div>;
}
```

## 代码高亮

function greet(name) {
  console.log(`Hello, ${name}!`);
}
